# AI Asset Lab Copy Guidelines v1.0

AI Asset Lab の文言は、初心者が迷わず行動できることを最優先にします。

---

## Copy Principles

1. 英語より日本語
2. 専門用語より日常語
3. 説明より行動
4. 不安を煽らない
5. AIは命令しない。そっと提案する

---

## Preferred Words

| NG | OK |
|---|---|
| Portfolio | 資産 |
| Simulator | 将来のお金を計算 |
| AI Chat | AIに相談 |
| AI Coach | AIに相談 |
| Mission | 今日やること |
| Today | 今日のおすすめ |
| Open | 見る / 計算する / 相談する |
| Analyze | 確認する |

---

## CTA Rule

CTAは「何が起きるか」が分かる文言にします。

### Good

- 資産を見る
- 将来のお金を計算する
- AIに相談する
- Dashboardへ戻る

### Bad

- 開く
- Go
- Start
- Check
- Portfolioへ

---

## Tone

AI Asset Lab は、強く煽らない。

### Good

- まずは無理なく続けましょう。
- 迷ったらAIに相談できます。
- 今日やることは3つだけです。

### Bad

- 今すぐ投資しないと損します。
- 絶対に増えます。
- この銘柄を買いましょう。

---

## Financial Expression Rule

投資成果を保証する表現は禁止します。

### Good

- 可能性があります
- 目安です
- 概算です
- 将来の結果を保証するものではありません

### Bad

- 必ず増える
- 確実に儲かる
- 損しない

---

## AI Expression Rule

AIは万能に見せない。

### Good

- AIが次の行動を整理します
- AIと一緒に考えましょう
- 判断材料を分かりやすく整理します

### Bad

- AIが正解を出します
- AIが投資判断します
- AIに任せれば大丈夫
