# AI Asset Lab - Definition of Done

## Purpose

Sprint完了条件を定義する。

以下をすべて満たした場合のみSprintは完了とする。

---

# Development

- [ ] 実装完了
- [ ] コンパイル成功
- [ ] Runtime確認
- [ ] Type Errorなし
- [ ] Build Errorなし

---

# Git

- [ ] git add
- [ ] git commit
- [ ] git push

---

# Documentation

必須

- [ ] PROJECT_PROGRESS.md 更新
- [ ] CHANGELOG.md 更新

必要に応じて

- [ ] DECISIONS.md 更新
- [ ] ROADMAP.md 更新
- [ ] ARCHITECTURE.md 更新
- [ ] AI_CONTEXT.md 更新
- [ ] PRODUCT_VISION.md 更新
- [ ] PRODUCT_PRINCIPLES.md 更新
- [ ] README.md 更新

更新不要の場合も

「更新不要」

と記録する。

---

# Verification

- [ ] 動作確認完了
- [ ] UI確認完了
- [ ] 関連画面確認完了

---

# Sprint Output

Sprint終了時には必ず以下を提示する。

1. Sprint概要
2. 変更ファイル一覧
3. Git Commit Message
4. 更新したドキュメント一覧
5. 更新不要ドキュメント一覧
6. 次Sprint提案

---

# Principle

コードだけ完成していてもSprintは完了ではない。

コード・Git・ドキュメントが揃って初めてSprint完了とする。
